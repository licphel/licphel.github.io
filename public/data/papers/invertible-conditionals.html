Overview

We train autoregressive models on either label-to-object generation or object-to-label recognition and compare three ways of using the learned relation: the trained task itself, external candidate search with the learned conditional, and the model's native prediction in the opposite direction.

On serialized digits, generation-only Qwen reaches 97.1% style-OOD accuracy when candidate labels are scored using the image likelihood, while native reverse candidate accuracy is 11.3%. Recognition-only training produces the complementary pattern: the learned recognizer retrieves the target object from candidate pools while native generation remains weak. The study also includes Shapes, Topology, Count1D, Llama replications, ASCIIEval, and tokenized-image MNIST experiments.

The central finding is a gap between a relation that can be inverted through an external search procedure and an inverse computation that the model executes directly.
